# Sakai

Independent cybersecurity blogger and security researcher based in South Korea.

I run **꿈을꾸는 파랑새 (Dreaming Bluebird)**, a Korean-language blog where I document and share what I learn through hands-on analysis of cybersecurity threats.

## 🔐 Areas of Interest

- Malware analysis
- Phishing and malicious website analysis
- APT and threat research
- Windows security
- Cybersecurity tools and software
- Security-related technical research

My blog focuses on analyzing real-world malware, phishing campaigns, suspicious files, and security incidents.

I try to explain not only what a threat does, but also how it works from a technical perspective.

🌐 **Blog:** [https://wezard4u.tistory.com](https://wezard4u.tistory.com)

## 🌏 Open-Source Localization
