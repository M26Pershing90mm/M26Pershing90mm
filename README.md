## 👤 About Me

I run **꿈을 꾸는 파랑새 (Dreaming Bluebird)**, a Korean-language cybersecurity blog where I document and share hands-on analysis of real-world security threats.

My work focuses on understanding not only **what a threat does**, but also **how it works technically**.

I publish practical analysis of malware, phishing campaigns, suspicious files, malicious websites, Windows security issues, and related cybersecurity topics.
